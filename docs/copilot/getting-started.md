# VS Codeで GitHub Copilotを始める

GitHub Copilotは、Visual Studio Codeでのコード記述方法を変えます。このハンズオンチュートリアルでは、完全なタスク管理 Web アプリケーションを構築しながら、VS Codeの AI 機能を発見します。複数のファイル全体で機能を実装する自律エージェント、インテリジェントなインライン候補、インラインチャットによる正確な編集、統合されたスマートアクション、強力なカスタマイズオプションです。

このチュートリアルの終わりには、実際に動作するWebアプリケーションと、開発スタイルに適応するカスタマイズされた AI コーディングセットアップの両方ができあがります。

<div class="docs-action" data-show-in-doc="true" data-show-in-sidebar="true" title="サンプルアプリを作成">
VS Codeのチャットを使用してサンプルアプリケーションを一度に生成します。

* [VS Codeで開く](vscode://GitHub.Copilot-Chat/chat?agent=agent%26prompt=%23newWorkspace%20task%20manager%20web%20application%20with%20the%20ability%20to%20add%2C%20delete%2C%20and%20mark%20tasks%20as%20completed.%20Add%20the%20code%2C%20custom%20instructions%2C%20and%20all%20custom%20agent%20definitions%20to%20this%20new%20workspace%20as%20described%20in%20https%3A%2F%2Fcode.visualstudio.com%2Fdocs%2Fcopilot%2Fgetting-started%0AAsk%20the%20user%20which%20tech%20stack%20they%20want%20to%20use.)

</div>

## 前提条件

* コンピューターにVS Codeがインストールされています。[Visual Studio Codeのウェブサイト](https://code.visualstudio.com/)からダウンロードしてください。

* GitHub Copilotへのアクセス。以下の手順に従って[VS CodeでGitHub Copilotをセットアップ](/docs/copilot/setup.md)してください。

    > [!TIP]
    > Copilotのサブスクリプションがない場合でも、VS Code内から直接Copilotを使用するために登録でき、月単位のインライン候補とチャットインタラクションの制限が付いています。

## ステップ1:インライン候補を試す

AI搭載のインライン候補は、入力時に表示され、より速く、エラーが少ないコード記述を支援します。タスクマネージャーの基盤構築を始めましょう。

1. プロジェクト用の新しいフォルダを作成し、VS Codeで開きます。

1. `index.html`という名前の新しいファイルを作成します。

1. 以下を入力し始めると、入力時にVS Codeがインライン候補(_ゴーストテキスト_)を提供します:

    ```html
    <!DOCTYPE html>
    ```

    ![Copilotが HTML 構造をインライン候補として提示する画面のスクリーンショット。](./images/getting-started/html-completion.png)

    言語モデルが[非決定的](/docs/copilot/concepts/language-models.md#key-characteristics)であるため、異なる候補が表示される場合があります。

1. `kbstyle(Tab)`を押して候補を承認します。

    おめでとうございます!最初のAI搭載インライン候補を承認しました。

1. HTML構造の構築を続けます。`<body>`タグ内で、以下を入力し始めます:

    ```html
    <div class="container">
        <h1>My Task Manager</h1>
        <form id="task-form">
    ```

    アプリケーション構造を構築するときに、VS Codeが関連する HTML 要素を引き続き提示する様子に注意してください。

1. 複数の候補が表示される場合は、ゴーストテキストの上にマウスを置いてナビゲーションコントロールを表示するか、`kb(editor.action.inlineSuggest.showNext)`と`kb(editor.action.inlineSuggest.showPrevious)`を使用してオプションを切り替えます。

    ![インライン候補のナビゲーションコントロールを表示する画面のスクリーンショット。](./images/getting-started/inline-suggestion-navigation.png)

インライン候補は入力時に自動的に機能し、パターンとプロジェクトのコンテキストから学習します。ボイラープレートコード、HTML構造、繰り返しパターンの記述に特に役立ちます。

## ステップ2:エージェントで完全な機能を構築

AI エージェントはVS Codeの最も強力なAI機能です。自然言語プロンプトが与えられると、複数のファイル全体で複雑な機能を自律的に計画および実装します。タスクマネージャーアプリケーションのコア機能を先ほど使用しましょう。

1. `kb(workbench.action.chat.open)`を押すか、VS Codeタイトルバーのチャットアイコンを選択して、チャットビューを開きます。

    チャットビューは、自然言語プロンプトを使用してAIと相互作用する場所です。継続的な会話を行い、リクエストを反復的に改善してより良い結果を得られます。

1. エージェントドロップダウンメニューで**エージェント**を選択して、AIがリクエストをエンドツーエンドで独立して実装できるようにします。

    ![チャットビューのエージェントピッカーを表示するスクリーンショット。](./images/getting-started/agent-mode-selection.png)

    > [!IMPORTANT]
    > エージェントオプションが表示されない場合は、VS Codeの設定で エージェントが有効になっていることを確認してください(`setting(chat.agent.enabled)`)。組織がエージェントを無効にしている場合もあります。管理者に連絡して、この機能を有効にしてください。

1. 次のプロンプトを入力し、`kbstyle(Enter)`を押します。エージェントがリクエストを分析し、ソリューションの実装を開始します。

    ```prompt
    完全なタスク管理Webアプリケーションを作成し、タスクを追加、削除、および完了としてマークできる機能を含めます。最新のCSSスタイルを含め、レスポンシブにします。セマンティックHTMLを使用し、アクセシビリティを確保します。マークアップ、スタイル、スクリプトを独自のファイルに分離します。
    ```

    エージェントが要求を実装するために必要なファイルとコードを生成する様子を観察してください。`index.html`ファイルの更新、スタイリング用の`styles.css`ファイルの作成、機能用の`script.js`ファイルの作成が表示されます。

    > [!TIP]
    > 異なる言語モデルは異なる強みを持つ場合があります。チャットビューのモデルドロップダウンを使用して、言語モデルを切り替えます。

1. 生成されたファイルを確認し、**保持**を選択してすべての変更を承認します。

1. 統合ブラウザーでVS Codeの`index.html`ファイルを開きます。ファイルを右クリックして**プレビューを表示**を選択してください。タスクを追加し、完了としてマークし、削除できます。

1. ここで、追加機能を追加しましょう。チャット入力ボックスに次のプロンプトを入力します:

    ```prompt
    すべてのタスク、完了したタスクのみ、または保留中のタスクのみを表示するボタンを備えたフィルターシステムを追加します。既存のデザインに合わせてスタイルを更新します。
    ```

    エージェントが複数のファイル全体の変更を調整して、この機能を完全に実装する様子に注意してください。

エージェントは高度な要件を理解し、それらを実行可能なコードに変換するのに優れています。新機能の実装、コードの大規模なセクションのリファクタリング、または最初からアプリケーション全体を構築するのに最適です。

## ステップ3:インラインチャットで正確な調整を行う

エージェントは大きな機能を処理する一方で、エディターのインラインチャットはファイル内の特定のコードセクションへの対象となった改善に最適です。タスクマネージャーアプリを強化するために使用しましょう。

1. JavaScriptファイルを開き、新しいタスクを追加するコードを見つけます。

1. コードブロックを選択し、`kb(inlinechat.start)`を押してエディターのインラインチャットを開きます。

    ![選択されたコードブロックに対してインラインチャットが開始される画面のスクリーンショット。](./images/getting-started/inline-chat-start.png)

    > [!NOTE]
    > 言語モデルが非決定的であるため、実際のコードは異なる場合があります。

1. 次のプロンプトを入力します:

    ```text
    入力検証を追加して、空のタスクが追加されないようにし、タスクテキストから空白をトリムします。
    ```

    インラインチャットが選択されたコードに特に焦点を当て、対象となった改善を行う様子に注意してください。

    ![選択された関数に検証を追加するインラインチャットを表示するスクリーンショット。](./images/getting-started/inline-chat-validation.png)

1. 変更を確認し、**保持**を選択して適用します。

エディターのインラインチャットは、より広いコードベースに影響を与えずに、エラー処理の追加、個別の関数のリファクタリング、バグの修正など、小さく焦点を絞った変更を行うのに最適です。

## ステップ4:AI体験をカスタマイズ

チャットをカスタマイズすることで、特定のニーズとコード記述スタイルに合わせて引伸ばせます。カスタム命令を設定し、特化したカスタムエージェントを構築できます。プロジェクト用の完全なカスタマイズセットアップを作成しましょう。

### カスタム命令を作成

カスタム命令は、コード記述の設定と基準についてAIに指示します。これらはすべてのチャットインタラクションに自動的に適用されます。

1. プロジェクトルートに`.github`というフォルダを作成します。

1. `.github`フォルダ内に`copilot-instructions.md`というファイルを作成します。

1. 次の内容を追加します:

    ```markdown
    # プロジェクト全般のコーディングガイドライン

    ## コードスタイル
    - セマンティックHTML5要素(header、main、section、article など)を使用する
    - const/let、アロー関数、テンプレートリテラルなどの最新JavaScript(ES6+)機能を推奨する

    ## 命名規則
    - コンポーネント名、インターフェース、型エイリアスにはPascalCaseを使用する
    - 変数、関数、メソッドにはcamelCaseを使用する
    - プライベートクラスメンバーのプレフィックスにアンダースコア(_)を使用する
    - 定数にはALL_CAPSを使用する

    ## コード品質
    - 目的を明確に説明する意味のある変数名と関数名を使用する
    - 複雑なロジックについて有用なコメントを含める
    - ユーザー入力とAPIコールのエラー処理を追加する
    ```

1. ファイルを保存します。これらの命令はこのプロジェクトのすべてのチャットインタラクションに適用されるようになります。

1. カスタム命令をテストするには、エージェントに新機能を追加するよう依頼します:

    ```prompt
    タスクマネージャーにダークモード切り替えボタンを追加します。
    ```

    生成されたコードが指定したガイドラインに従う方法に注意してください。VS Codeは、特定のファイルタイプに対して命令を適用するなど、より高度なカスタム命令をサポートしています。

> [!TIP]
> チャットで`/init`スラッシュコマンドを使用して、プロジェクトの構造とコード記述パターンに基づいてカスタム命令を自動的に生成します。既存のコードベースがあり、AI支援の準備をしたい場合に便利です。

### コードレビュー用のカスタムエージェントを作成

カスタムエージェントは、特定のタスク用に特化したAI ペルソナを作成します。「コードレビュー」エージェントを作成してくださいに焦点を当て、コードを分析し、フィードバックを提供します。カスタムエージェント定義では、AIの役割、特定のガイドライン、使用できるツールを定義できます。

1. コマンドパレットを開き、**Chat: New Custom Agent**コマンドを実行します。

1. `.github/agents`を場所として選択します。

    このオプションはカスタムエージェントをワークスペースに追加し、プロジェクトを開くときに他のチームメンバーがそれを使用できるようにします。

1. カスタムエージェントに「Reviewer」という名前を付けます。これにより、`.github/agents`フォルダに`Reviewer.agent.md`という新しいファイルが作成されます。

1. ファイルの内容を次の内容に置き換えます。このカスタムエージェントはコード変更を許可しないことに注意してください。

    ```markdown
    ---
    name: 'Reviewer'
    description: 'Review code for quality and adherence to best practices.'
    tools: ['vscode/askQuestions', 'vscode/vscodeAPI', 'read', 'agent', 'search', 'web']
    ---
    # Code Reviewer agent

    経験豊かなシニア開発者として、徹底的なコードレビューを実施しています。あなたの役割は、直接コード変更を行わずに、[プロジェクト基準](../copilot-instructions.md)に対するコード品質、ベストプラクティス、および遵守についてレビューすることです。

    コードをレビューする場合、明確な見出しを使用して、レビュー中のコードからの特定の例を含むフィードバックを構造化します。

    ## 分析フォーカス
    - コード品質、構造、およびベストプラクティスを分析する
    - 潜在的なバグ、セキュリティ問題、またはパフォーマンスの問題を特定する
    - アクセシビリティとユーザー体験の考慮事項を評価する

    ## 重要なガイドライン
    - 必要に応じて、設計上の決定について説明する質問をする
    - 何を変更すべきか、そしてなぜかについて説明することに焦点を当てる
    - 具体的なコード変更を直接書いたり提案したりしないでください
    ```

1. ファイルを保存します。チャットビューで、エージェントピッカーからこのカスタムエージェントを選択できるようになります。

    ![エージェントピッカーで Reviewer カスタムエージェント を表示するスクリーンショット。](./images/getting-started/custom-mode-dropdown.png)

1. 次のプロンプトを入力して、エージェントピッカーから**Reviewer**を選択して、カスタムエージェントをテストします:

    ```prompt-Reviewer
    プロジェクト全体をレビュー
    ```

   AIがコードレビュアーとして動作し、改善のための分析と提案を提供していることに注意してください。

    ![カスタムレビュアーエージェントがコードを分析する画面のスクリーンショット。](./images/getting-started/custom-reviewer-mode.png)

## ステップ5:スマートアクションを使用して事前構築されたAI支援を活用

スマートアクションは、VS Codeのインターフェース内に直接統合されたAI機能を提供し、開発ワークフローにシームレスに接続します。チャットインタラクションとは異なり、スマートアクションは必要な場所に分気的に表示されます。例としてコミットメッセージの生成を探索しましょう。

1. `kb(workbench.view.scm)`を押すか、アクティビティバーのソース管理アイコンを選択して、**ソース管理**ビューを開きます。

1. まだプロジェクト用にGitリポジトリを初期化していない場合は、ソース管理ビューで**リポジトリを初期化**を選択して初期化します。

1. コミットするファイルの横にある**+**ボタンを選択して、変更をステージします。

1. **スパークルアイコン**を選択して、ステージされた変更に基づいてコミットメッセージを生成します。

    AIは、ステージされた変更を分析し、従来のコミット標準に従う説明的なコミットメッセージを生成します。AIは以下を考慮します:

    * 変更されたファイル
    * 変更の性質(機能の追加、バグ修正、リファクタリング)
    * 変更の範囲と影響

    ![ソース管理ビューで生成されたコミットメッセージを表示するスクリーンショット。](./images/getting-started/generated-commit-message.png)

1. 生成されたメッセージを確認します。メッセージに満足している場合は、コミットに進みます。異なるスタイルやフォーカスが必要な場合は、スパークルアイコンを再度選択して代替メッセージを生成します。

コミットメッセージ生成などのスマートアクションは、チャットインターフェースへのコンテキストスイッチを必要とせずに、既存のワークフローにAIが自然に統合される方法を実証しています。VS Codeにはデバッグ、テストなどに役立つ多くの他のスマートアクションがあります。

## 次のステップ

おめでとうございます!完全なタスク管理アプリケーションを構築し、VS Code全体のAIを効果的に使用する方法を学習しました。

他のカスタマイズオプションを探索することで、AIの機能をさらに強化できます:

* 計画、デバッグ、ドキュメンテーションなど、異なるタスク用の特化したエージェントを追加します。
* 特定のプログラミング言語またはフレームワーク用のカスタム命令を作成します。
* MCP(Model Context Protocol)サーバーまたはVS Code拡張機能からの追加ツールを使用してAIの機能を拡張します。
