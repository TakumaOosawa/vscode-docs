# Visual Studio Codeのクラウドエージェント

クラウドエージェントはリモートインフラストラクチャで実行され、プルリクエストを通じたチーム協業のためにGitHubリポジトリと統合されます。例えば、GitHub CopilotコーディングエージェントはGitHubのインフラストラクチャで実行され、機能の実装、コードレビューのフィードバック対応、プルリクエストの自動生成が可能です。

この記事では、クラウドエージェントの主な機能と、シンプルから複雑まで様々なコーディングタスク向けのクラウドエージェントセッションを開始・管理する方法について説明します。

## クラウドエージェントとは？

ローカルマシンで実行されるローカルおよびバックグラウンドエージェントとは異なり、Copilotコーディングエージェントのようなクラウドエージェントはリモートインフラストラクチャで実行されます。VS Codeの統一されたチャットビューからすべてのクラウドエージェントセッションを表示および管理できます。このビューでは、VS Codeから直接新しいクラウドエージェントセッションを作成したり、ローカルまたはバックグラウンドエージェントの会話をクラウドエージェントに移譲したりすることもできます。

VS Codeはcopilotコーディングエージェント、Claudeなどの[サードパーティエージェント](/docs/copilot/agents/third-party-agents.md)など、異なるクラウドエージェントをサポートしています。

クラウドエージェントはユーザーの操作なしでリモートで実行されるため、明確なスコープと必要なコンテキストすべてを備えたタスクに最適です。プルリクエストとの統合により、チーム協業に非常に効果的です。

リモート実行環境のため、クラウドエージェントはVS Code組み込みツールとランタイムコンテキスト（失敗したテストやテキスト選択など）に直接アクセスできません。クラウドエージェントサービスで設定されているMCPサーバーと言語モデルに限定されます。

クラウドエージェントにタスクを割り当てるには、チャットビューから直接新しいクラウドセッションを作成するか、VS Codeのローカルまたはバックグラウンドエージェント会話をクラウドエージェントに移譲できます。

### GitHub Copilotコーディングエージェント

**GitHub Copilotコーディングエージェント**は、Copilotサブスクリプションを使用してVS Codeで利用可能な主要なクラウドエージェントです。

主な機能は以下の通りです：

* GitHubリポジトリ全体での大規模なリファクタリング
* 高レベルの要件から完全な機能の実装
* 詳細な説明を含む自動プルリクエスト生成
* コードレビュー統合とフィードバック対応

### サードパーティクラウドエージェント

VS CodeはClaudeコーディングエージェントやCodexコーディングエージェントなどのサードパーティクラウドエージェントをクラウドエージェントセッションのオプションとしてサポートしています。VS Codeで使用する前に、Copilotアカウント設定でクラウドのサードパーティエージェントサポートを有効にする必要があります。

VS Codeでプロバイダーのクラウドエージェントを使用するために、プロバイダーのVS Code拡張機能をインストールする必要はありません。

[VS Codeのサードパーティエージェント](/docs/copilot/agents/third-party-agents.md)と、それらを有効にする方法の詳細をご覧ください。

## クラウドエージェントセッションの開始

クラウドエージェントセッションは、クラウドエージェントにチャットプロンプトを直接送信するか、進行中のローカルまたはバックグラウンド会話をクラウドエージェントに移譲することで開始できます。進行中の会話を移譲することは、自律実行前に初期の明確化または計画が必要な複雑なタスクに特に役立ちます。

ブラウザで作業することを希望する場合は、GitHub.comから[GitHub Copilotコーディングエージェント](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/manage-agents)を使用して、クラウドエージェントセッションを直接開始することもできます。

### 新しいクラウドエージェントセッションの作成

新しいクラウドエージェントセッションを作成するには：

1. チャットビューで、セッションリストドロップダウンから**新規チャット**を選択し、セッションタイプドロップダウンから**クラウド**を選択します

    または、コマンドパレット（`kb(workbench.action.showCommands)`）から**チャット：新規クラウドエージェント**コマンドを実行できます。

1. ドロップダウンからクラウドエージェントプロバイダーを選択し、必要に応じてカスタムエージェントと言語モデルを選択します。

1. プロンプトを入力し、クラウドエージェントにタスクを処理させます

   たとえば、以下のように入力できます：

   ```text
   認証モジュールをリファクタリングしてセキュリティとパフォーマンスを向上させてください。トークン管理にOAuth2とJWTを実装し、ユーザーセッションのデータベースクエリを最適化してください。
   ```

1. クラウドエージェントはリモートでタスクの処理を開始します。チャットビューでセッションの進行状況を監視し、引き続きそれと対話できます。

> [!NOTE]
> GitHub.comでCopilotコーディングエージェントに課題またはプルリクエストを割り当てた場合、セッションは自動的にVS Codeのセッションリストに表示されます。

### エージェントセッションをクラウドエージェントに移譲

複雑なタスクの場合、まずVS Codeチャットでローカルエージェント（例えば計画エージェント）と対話して要件を明確化し、その後タスクをクラウドエージェントに移譲して自律実行させることが役立ちます。ローカルエージェント会話をクラウドエージェントセッションに移譲する場合、チャット全体のコンテキストがクラウドエージェントに渡されます。

ローカルエージェントセッションをクラウドエージェントセッションに移譲するには：

1. チャットビューで進行中のローカルエージェントセッションを開きます。

1. セッションタイプドロップダウンを選択し、**クラウド**を選択してセッションをクラウドエージェントとして続行します。

    [計画エージェント](/docs/copilot/agents/planning.md)を使用している場合は、**実装開始**ドロップダウンから**クラウドで続行**を選択して、計画実装をクラウドエージェントセッションで実行できます

バックグラウンドエージェントセッションをクラウドエージェントセッションに移譲するには、バックグラウンドエージェントセッションのチャット入力に`/delegate`と入力します。このコマンドはチャット履歴全体とコンテキストを新しいクラウドエージェントセッションに渡し、その後チャットビューで監視できます。

## クラウドエージェントセッションの表示と管理

VS Codeのチャットビューからすべてのクラウドエージェントセッションを表示および管理できます。フィルタオプションから**クラウドエージェント**を選択して、セッションリストをフィルタリングしクラウドエージェントセッションのみを表示します。

![VS Code チャットビューのクラウドエージェントフィルタのスクリーンショット](../images/cloud-agents/cloud-agent-filter.png)

リストからクラウドエージェントセッションを選択して、セッション詳細をチャットビューで開きます。エディタタブ（チャットエディタ）でセッションを表示することを希望する場合は、セッションを右クリックし、**エディタとして開く**を選択します。

![VS Codeのチャットエディタとして表示されるクラウドエージェントセッションのスクリーンショット](../images/cloud-agents/cloud-agent-session.png)
