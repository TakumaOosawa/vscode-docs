# VS Codeのクラウドエージェント

クラウドエージェントはリモートインフラストラクチャ上で実行され、プルリクエストを通じたチームコラボレーションのためにGitHubリポジトリと統合されます。例えば、GitHub CopilotコーディングエージェントはGitHubのインフラストラクチャ上で実行され、機能を実装したり、コードレビューのフィードバックに対応したり、プルリクエストを自動的にオープンできます。

この記事では、クラウドエージェントの主な機能、および単純なものから複雑なものまで様々なコーディングタスクに対してクラウドエージェントセッションを開始および管理する方法をカバーしています。

## クラウドエージェントとは何ですか?

ご使用のローカルマシン上で実行されるローカルおよびバックグラウンドエージェントとは異なり、Copilotコーディングエージェントなどのクラウドエージェントはリモートインフラストラクチャ上で実行されます。VS Codeの統合されたチャットビューからすべてのクラウドエージェントセッションを表示および管理できます。このビューでは、VS Codeから直接新しいクラウドエージェントセッションを作成するか、ローカルまたはバックグラウンドエージェントの会話をクラウドエージェントに引き継ぐこともできます。

VS Codeは、Copilotコーディングエージェントや[サードパーティエージェント](/docs/copilot/agents/third-party-agents.md)（claudeやCodexなど）などのさまざまなクラウドエージェントをサポートしています。

クラウドエージェントはユーザーの操作なしでリモート実行されるため、明確に定義されたスコープとすべての必要なコンテキストを持つタスクに非常に適しています。プルリクエストとの統合により、チームコラボレーションに非常に効果的です。

リモート実行環境のため、クラウドエージェントはVS Codeの組み込みツールとランタイムコンテキスト（失敗したテストやテキスト選択など）に直接アクセスできません。クラウドエージェントサービスで構成されているMCPサーバーと言語モデルのみに制限されます。

クラウドエージェントにタスクを割り当てるには、チャットビューから直接新しいクラウドセッションを作成するか、VS Codeからローカルまたはバックグラウンドエージェントの会話をクラウドエージェントに引き継ぐことができます。

### GitHub Copilot コーディングエージェント

**GitHub Copilotコーディングエージェント**は、Copilot登録でVS Codeで利用可能なプライマリクラウドエージェントです。

主な機能は以下の通りです:

* GitHubリポジトリ全体にわたる大規模なリファクタリング
* 高レベルの要件からの完全な機能実装
* 詳細な説明を含む自動プルリクエスト生成
* コードレビュー統合とフィードバック対応

### サードパーティクラウドエージェント

VS Codeは、Claude CodingエージェントやCodex Codingエージェントなどのサードパーティクラウドエージェントをクラウドエージェントセッションのオプションとしてサポートしています。VS Codeでサードパーティエージェントを使用する前に、Copilotアカウント設定でクラウドのサードパーティエージェントサポートを有効にする必要があります。

VS Codeでクラウドエージェントを使用するために、プロバイダーのVS Code拡張機能をインストールする必要はありません。

[VS Codeのサードパーティエージェント](/docs/copilot/agents/third-party-agents.md)について詳しく学び、それらを有効にする方法を確認してください。

## クラウドエージェントセッションを開始する

クラウドエージェントセッションは、クラウドエージェントにチャットプロンプトを直接送信するか、進行中のローカルまたはバックグラウンドの会話をクラウドエージェントに引き継ぐことで開始できます。進行中の会話を引き継ぐことは、自動実行前に初期的な明確化や計画が必要な複雑なタスクに特に有用です。

ブラウザで作業することを希望する場合は、[GitHub Copilotコーディングエージェント](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/manage-agents)を使用してGitHub.comから直接クラウドエージェントセッションを開始することもできます。

### 新しいクラウドエージェントセッションを作成する

新しいクラウドエージェントセッションを作成するには:

1. チャットビューで、セッションリストドロップダウンから**新しいチャット**を選択し、セッションタイプドロップダウンから**クラウド**を選択します。

    別の方法として、コマンドパレット（`kb(workbench.action.showCommands)`）から**Chat: New Cloud Agent**コマンドを実行できます。

1. ドロップダウンからクラウドエージェントプロバイダーを選択し、必要に応じてカスタムエージェントとモデルを選択します。

1. プロンプトを入力し、クラウドエージェントがタスクに取り組むようにします。

   例えば、次のように入力できます:

   ```text
   認証モジュールをリファクタリングしてセキュリティとパフォーマンスを改善してください。トークン管理にはOAuth2とJWTを実装し、ユーザーセッションのデータベースクエリを最適化してください。
   ```

1. クラウドエージェントはリモートでタスクに取り組み始めます。チャットビューでセッションの進行状況を監視し、引き続きセッションと対話できます。

> [!NOTE]
> GitHub.comでCopilotコーディングエージェントに問題またはプルリクエストを割り当てた場合、セッションはVS Codeのセッションリストに自動的に表示されます。

### エージェントセッションをクラウドエージェントに引き継ぐ

複雑なタスクでは、まずVS Codeチャット内のローカルエージェント（例えばPlanエージェント）と対話して要件を明確にしてから、タスクをクラウドエージェントに引き継いで自動実行させることが役に立つことがあります。ローカルエージェントの会話をクラウドエージェントセッションに引き継ぐと、チャット全体のコンテキストがクラウドエージェントに渡されます。

ローカルエージェントセッションをクラウドエージェントセッションに引き継ぐには:

1. チャットビューで進行中のローカルエージェントセッションを開きます。

1. セッションタイプドロップダウンを選択し、**クラウド**を選択してセッションをクラウドエージェントとして続行します。

    [Planエージェント](/docs/copilot/agents/planning.md)を使用している場合は、**実装開始**ドロップダウンから**クラウドで実行**を選択して、計画実装をクラウドエージェントセッションで実行できます。

バックグラウンドエージェントセッションをクラウドエージェントセッションに引き継ぐには、バックグラウンドエージェントセッションのチャット入力に`/delegate`と入力します。このコマンドは完全なチャット履歴とコンテキストを新しいクラウドエージェントセッションに渡し、チャットビューで監視できます。

## クラウドエージェントセッションを表示および管理する

VS Codeのチャットビューからすべてのクラウドエージェントセッションを表示および管理できます。フィルタオプションから**クラウドエージェント**を選択してセッションリストをフィルタリングし、クラウドエージェントセッションのみを表示します。

![VS Codeチャットビューのクラウドエージェントフィルタのスクリーンショット。](../images/cloud-agents/cloud-agent-filter.png)

リストからクラウドエージェントセッションを選択して、チャットビューでセッション詳細を開きます。セッションをエディタタブ（チャットエディタ）で表示する場合は、セッションを右クリックして**エディタで開く**を選択します。

![VS Codeのチャットエディタとしてのクラウドエージェントセッションのスクリーンショット。](../images/cloud-agents/cloud-agent-session.png)
