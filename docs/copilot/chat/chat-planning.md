# VS Codeチャットでのプランニング

Visual Studio Codeチャットのエージェントは、複雑なコーディングタスクを自律的に実行するのに役立ちます。Planエージェントを使用すると、実装を開始する前に詳細な実装プランを作成し、すべての要件が満たされていることを確認できます。TODOリストを使用すると、エージェントは全体的な目標に集中し続け、進捗状況を効果的に追跡できます。

プランとTODOを使用すると、コーディングを開始する前にエージェントと一緒に実装の詳細を構成およびレビューできるため、生成されるコードの品質と信頼性が向上します。また、プランとTODOは、より複雑で長いタスクを体系的に処理するためのより良いガイダンスをエージェントに提供します。

この記事では、PlanエージェントやTODOリストなど、VS Codeチャットで開発タスクを調査および計画する方法について説明します。

## 詳細なタスク調査のためのPlanエージェント

組み込みのPlanエージェントは、実行前に詳細な実装プランを作成するためにあなたと協力します。これにより、コードを変更する前にすべての要件が検討され、対処されていることが保証されます。Planエージェントは、プランがレビューされ承認されるまで、コードの変更を行いません。承認されたら、プランをデフォルトのエージェントに引き渡すか、さらなる改良、レビュー、またはチームでの議論のためにプランを保存できます。

Planエージェントは以下のように設計されています:

* 読み取り専用ツールとコードベース分析を使用してタスクを包括的に調査し、要件と制約を特定する
* タスクを管理可能で実行可能なステップに分解し、あいまいな要件に対する未解決の質問を含める
* ユーザーのレビューと反復のために、標準化されたプラン形式に基づいた簡潔なプランドラフトを提示する

### タスクを計画する方法

1. `kb(workbench.action.chat.open)`を押してチャットビューを開き、エージェントのドロップダウンから**Plan**を選択します。

2. 高レベルなタスク（機能、リファクタリング、バグなど）を入力して送信します。

    例えば:
    * "OAuth2とJWTを使用したユーザー認証システムを実装する"
    * "すべてのAPIエンドポイントに単体テストを追加する"
    * "送信後に保存してもフォームフィールドがリセットされない"

3. 提案されたプランドラフトをプレビューし、反復のためのフィードバックを提供します。

    Planエージェントは、高レベルの要約とステップの内訳（明確化のための未解決の質問を含む）を提供します。

    ![チャットビューでPlanエージェントによって生成されたサンプルプランを示すスクリーンショット。要約、ステップの内訳、および未解決の質問が含まれています。](../images/chat-planning/plan-agent-sample.png)

    > [!TIP]
    > 実装前にプランを洗練させるために、プランモードに留まってください。要件を明確にしたり、スコープを調整したり、未解決の質問に対処したりするために、何度も繰り返すことができます。これにより、コードを変更する前に強固な基盤が確保されます。

4. 確定したら、ボタンを使用してプランの実装を開始するか、エディターでプランを開いてさらに確認します。

    同じチャットセッションでプランを実装するか、バックグラウンドまたはクラウド[エージェントセッション](/docs/copilot/agents/overview.md)を開始して、バックグラウンドで自律的に実装に取り組むかを選択できます。

    プランの実装を開始する際も、「UIから開始する」や「ステップ1と2のみ」などの明確な指示を提供できます。

## TODOリストで進捗状況を追跡する

複雑なタスクに取り組む際、VS Codeのエージェントは進捗状況を追跡するためのTODOリストを作成します。TODOリストはリクエストを個々のタスクに分解し、AIが各ステップを完了すると自動的に更新されます。これにより、進捗状況を監視でき、長時間実行されるタスクの間もエージェントが集中し続けることができます。

<video src="../images/chat-planning/todo-list-demo.mp4" title="チャットリクエストの進捗状況を追跡するためのチャットビューのTODOリストコントロールを示すビデオ。" autoplay loop controls muted></video>

> [!TIP]
> 「ステップ1をxするように修正して」や「別のタスクを追加して」のような自然言語を使用して、TODOリストを更新できます。エージェントのTODOが期待どおりでない場合は、リストをクリアできますが、それ以外の場合、エージェントはあなたのフィードバックやリクエストの作業中に収集した情報に基づいて自動的に更新を管理します。
