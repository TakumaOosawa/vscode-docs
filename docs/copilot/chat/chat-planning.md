# VS Code Chatでの計画

Visual Studio Code Chatのエージェントは、複雑なコーディングタスクを自律的に実行するのに役立ちます。planエージェントを使用すると、実装を開始する前に詳細な実装計画を作成して、すべての要件が満たされていることを確認できます。todoリストを使用すると、エージェントは全体的な目標に集中し続け、進捗状況を効果的に追跡できます。

計画とtodoを使用すると、コーディングを開始する前にエージェントと実装の詳細を構造化してレビューできるため、生成されるコードの品質と信頼性が向上します。また、計画とtodoは、より複雑で長いタスクを体系的に処理するためのより良いガイダンスをエージェントに提供します。

この記事では、planエージェントやtodoリストなど、VS Code Chatで開発タスクを調査および計画する方法について説明します。

## 詳細なタスク調査のためのplanエージェント

組み込みのplanエージェントは、あなたと協力して、実行前に詳細な実装計画を作成します。これにより、コード変更が行われる前に、すべての要件が考慮され、対処されていることが確認されます。planエージェントは、計画がレビューされ承認されるまで、コード変更を行いません。承認されたら、計画をデフォルトのエージェントに引き渡すか、さらなる改良、レビュー、またはチームディスカッションのために保存できます。

planエージェントは以下を行うように設計されています:

* 読み取り専用ツールとコードベース分析を使用してタスクを包括的に調査し、要件と制約を特定する
* タスクを管理可能で実行可能なステップに分割し、曖昧な要件に対する未解決の質問を含める
* ユーザーレビューと反復のために、標準化された計画形式に基づいた簡潔な計画案を提示する

### タスクを計画する方法

1. `kb(workbench.action.chat.open)`を押してチャットビューを開き、エージェントのドロップダウンから**Plan**を選択します。

2. 高レベルのタスク(機能、リファクタリング、バグなど)を入力して送信します。

    例えば:
    * "OAuth2とJWTを使用したユーザー認証システムを実装する"
    * "すべてのAPIエンドポイントに単体テストを追加する"
    * "保存しても送信後にフォームフィールドがリセットされない"

3. 提案された計画案をプレビューし、反復のためのフィードバックを提供します。

    planエージェントは、明確化のための未解決の質問を含む、高レベルの要約とステップの内訳を提供します。

    ![チャットビューでplanエージェントによって生成されたサンプル計画を示すスクリーンショット。要約、ステップの内訳、および未解決の質問が含まれています。](../images/chat-planning/plan-agent-sample.png)

    > [!TIP]
    > 実装前に計画を洗練させるために、計画モードのままにしてください。要件を明確にし、スコープを調整し、未解決の質問に対処するために、何度も反復できます。これにより、コード変更が行われる前に強固な基盤が確保されます。

4. 確定したら、ボタンを使用して計画の実装を開始するか、エディターで計画を開いてさらにレビューします。

    同じチャットセッションで計画を実装するか、バックグラウンドまたはクラウド[エージェントセッション](/docs/copilot/agents/overview.md)を開始して、バックグラウンドで自律的に実装作業を行うかを選択できます。

    計画の実装を開始するときでも、「UIから始める」や「ステップ1と2のみ」などの明確な指示を提供できます。

## todoリストで進捗状況を追跡する

複雑なタスクに取り組む際、VS Codeのエージェントは進捗状況を追跡するためのtodoリストを作成します。todoリストはリクエストを個別のタスクに分割し、AIが各ステップを完了すると自動的に更新されます。これにより、進捗状況を監視でき、長時間実行されるタスク中にエージェントが集中し続けることができます。

<video src="../images/chat-planning/todo-list-demo.mp4" title="チャットリクエストの進捗状況を追跡するためのチャットビューのtodoリストコントロールを示すビデオ。" autoplay loop controls muted></video>

> [!TIP]
> 「ステップ1をxするように修正する」や「別のタスクを追加する」などの自然言語を使用して、todoリストを更新できます。エージェントのtodoが期待どおりでない場合はリストをクリアできますが、それ以外の場合は、フィードバックとリクエストの作業中に収集した情報に基づいて、エージェントが更新を自動的に管理します。
