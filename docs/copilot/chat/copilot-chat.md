# チャット概要

Visual Studio Codeのチャットにより、AI搭載のコーディング支援を自然言語で利用できます。コードに関する質問をしたり、複雑なロジックの理解を得たり、新機能を生成したり、バグを修正したりできます。すべて会話型のインターフェースで行えます。この記事では、チャットサーフェス、チャットセッションの設定方法、コンテキストの追加、効果的なプロンプトの作成、AI生成コードの確認方法について説明します。

## 前提条件

* [GitHub Copilot](/docs/copilot/setup.md)へのアクセス。サブスクリプションがない場合は、[Copilot無料プラン](https://github.com/github-copilot/signup)にサインアップしてCopilotを無料で使用できます。

## VS Codeでチャットにアクセス

VS Codeは複数の方法でAIチャット会話を開始できます。各方法は異なるワークフロー向けに最適化されています。VS Codeタイトルバーの**チャット**メニューまたは対応するキーボードショートカットを使用します。

![VS CodeコマンドセンターのCopilot Chatメニューのスクリーンショット。](images/copilot-chat/copilot-chat-menu-command-center.png)

| サーフェス | ショートカット | 最適な用途 | 詳細 |
|---|---|---|---|
| **チャットビュー** | `kb(workbench.action.chat.open)` | 複数ターンの会話、エージェントワークフロー、複数ファイルの編集。[エディタータブまたは別ウィンドウ](/docs/copilot/chat/chat-sessions.md#start-a-new-chat-session)としても利用可能。 | [チャットセッション](/docs/copilot/chat/chat-sessions.md) |
| **インラインチャット** | `kb(inlineChat.start)` | インプレイスコード編集とターミナルコマンド提案。 | [インラインチャット](/docs/copilot/chat/inline-chat.md) |
| **クイックチャット** | `kb(workbench.action.quickchat.toggle)` | 現在のビューを離れずに素早く質問できます。エディターの上部に軽量なチャットパネルを開きます。 | [クイックチャット](/docs/copilot/chat/inline-chat.md#use-quick-chat) |
| **コマンドライン** | `code chat` | VS Code外からチャットを開始します。 | [CLIドキュメント](/docs/configure/command-line.md#start-chat-from-the-command-line) |

## 最初のプロンプトを送信

チャットの動作を確認するため、基本的なアプリを作成してみます:

1. `kb(workbench.action.chat.open)`を押すか、VS Codeタイトルバーから**チャット**を選択してチャットビューを開きます。

1. エージェントピッカーからエージェントを選択します。例えば、**エージェント**を選択するとチャットは何をする必要があるかを自動的に判断し、ワークスペースに変更を加えます。[ビルトインエージェント](/docs/copilot/agents/overview.md)について詳しく学びます。

1. チャット入力フィールドに次のプロンプトを入力し、`kb(workbench.action.chat.submit)`を押して送信します:

    ```prompt
    Create a basic calculator app with HTML, CSS, and JavaScript
    ```

    エージェントはワークスペースに直接変更を適用し、例えば依存関係をインストールしたり、ビルドスクリプトを実行したりするためにターミナルコマンドも実行する場合があります。

1. エディターで[提案された変更を確認](/docs/copilot/chat/review-code-edits.md)し、それらを保持するか破棄するかを選択します。

> [!TIP]
> 完全なハンズオンチュートリアルについては、[エージェントチュートリアル](/docs/copilot/agents/agents-tutorial.md)に従ってください。

## リクエスト実行中にメッセージを送信

> [!NOTE]
> メッセージステアリングとキューイングは実験的機能です。

応答が完了するのを待たずに次のメッセージを送信できます。リクエストが進行中の場合、**送信**ボタンのドロップダウンを使用して新しいメッセージの処理方法を選択します:

* **キューに追加**: メッセージは待機し、現在の応答完了後に自動的に送信されます。
* **メッセージでステアリング**: 現在のリクエストは譲歩し、新しいメッセージがすぐに処理されます。
* **停止して送信**: 現在のリクエストをキャンセルし、新しいメッセージをすぐに送信します。

![送信ボタンドロップダウンが展開され、キューに追加、メッセージでステアリング、停止して送信のオプションが表示されたチャットビューのスクリーンショット。](../images/chat-sessions/send-dropdown.png)

複数の保留中メッセージがある場合は、ドラッグアンドドロップで並べ替えることができます。[リクエスト実行中にメッセージを送信する](/docs/copilot/chat/chat-sessions.md#send-messages-while-a-request-is-running)について詳しく学びます。

## チャットセッションを設定

チャットセッションを開始または調整する場合、3つの選択がAIの応答方法を決定します: 使用するエージェント、セッションが実行される場所、それを支えるLanguageModel。

### 実行場所を選択

エージェントセッションはワークフローに合わせて異なる環境で実行できます。チャットビューのセッションタイプドロップダウンからセッションタイプを選択します。

![チャットビューのセッションタイプドロップダウンを示すスクリーンショット。](../images/agents-overview/agent-type-dropdown-jan.png)

| セッションタイプ | 説明 |
|---|---|
| **ローカル** | マシン上のVS Codeで対話的に実行されます。即座のフィードバックが必要な探索的タスクに最適です。 |
| **バックグラウンド** | CLIを介してマシン上で自動的に実行されます。バックグラウンドで実行したい明確に定義されたタスクに最適です。 |
| **クラウド** | リモートインフラストラクチャで実行され、プルリクエストを開きます。チーム協働と明確に定義されたタスクに最適です。 |
| **サードパーティ** | AnthropicやOpenAIなどの外部プロバイダーからのエージェントを使用します。 |

セッション中にあるタイプから別のタイプにセッションを引き継ぐことができ、会話履歴全体が引き継がれます。[エージェントタイプ](/docs/copilot/agents/overview.md#types-of-agents)と[セッションを別のエージェントに引き継ぐ](/docs/copilot/agents/overview.md#hand-off-a-session-to-another-agent)について詳しく学びます。

### エージェントを選択

エージェントにより、チャットは異なるロールやペルソナを想定でき、特定のタスク向けに最適化されています。チャットビューのエージェントドロップダウンからエージェントを選択します。セッション中いつでもエージェント間を切り替えられます。

![異なるエージェントオプションが表示されたエージェントピッカーが展開されたチャットビューのスクリーンショット。](../images/customization/chat-mode-dropdown.png)

VS Codeは3つのビルトインエージェントを提供します:

* **エージェント**: 複数ファイル間で自動的に計画・実装し、ターミナルコマンドを実行し、ツールを呼び出します。
* **プラン**: コードを記述する前に、構造化されたステップバイステップの実装計画を作成します。計画が適切に見えたら実装エージェントに引き継ぎます。
* **質問**: ファイルを変更せずにコーディング概念、コードベース、またはVS Code自体についての質問に答えます。

より特殊なワークフローの場合は、特定のロール、利用可能なツール、LanguageModelを定義する独自の[カスタムエージェント](/docs/copilot/customization/custom-agents.md)を作成します。

[ビルトインエージェントとその機能](/docs/copilot/agents/local-agents.md)について詳しく学びます。

### 権限レベルを選択

権限ピッカーはセッション中にエージェントがツール承認に対して持つ自律性を制御します。チャット入力フィールドの権限ドロップダウンから権限レベルを選択します。

| 権限レベル | 説明 |
|---|---|
| **デフォルト承認** | 設定された承認設定を使用します。承認が必要なツールは確認ダイアログを表示します。 |
| **承認をバイパス** | 確認ダイアログを表示せずにすべてのツール呼び出しを自動承認します。 |
| **Autopilot** (プレビュー) | すべてのツール呼び出しを自動承認し、質問に自動応答し、エージェントはタスクが完了するまで自動的に作業を続けます。 |

[権限レベルとAutopilot](/docs/copilot/agents/agent-tools.md#permission-levels)について詳しく学びます。

### 言語モデルを選択

VS Codeはさまざまな言語モデルを提供します。それぞれは異なるタスク向けに最適化されています。高速なコーディングタスク向けに設計されたモデルもあれば、複雑な推論と計画に優れたモデルもあります。チャット入力フィールドのモデルドロップダウンを使用してニーズに最適なモデルを選択します。

![チャットビューの言語モデルドロップダウンのスクリーンショット。利用可能なモデルのドロップダウンリストが表示されています。](images/copilot-chat/chat-model-picker.png)

他のプロバイダーからモデルを追加し、チャットで使用することもできます。[VS Codeの言語モデル](/docs/copilot/customization/language-models.md)について詳しく学びます。

> [!NOTE]
> 利用可能なモデルのリストはCopilotサブスクリプションに基づいて異なる場合があり、時間とともに変更される可能性があります。[利用可能な言語モデル](https://docs.github.com/en/copilot/using-github-copilot/ai-models/changing-the-ai-model-for-copilot-chat?tool=vscode)の詳細については、GitHubCopilotドキュメントを参照してください。

## プロンプトにコンテキストを追加

適切なコンテキストを提供することにより、AIはより関連性が高く正確な応答を生成できます。

* **暗黙的コンテキスト**: VS Codeはアクティブファイル、現在の選択、ファイル名を自動的にコンテキストに含めます。エージェントを使用する場合、エージェントは追加のコンテキストが必要かどうかを自動的に判断します。

* **`#`メンション**: チャット入力で`#`を入力してファイル(`#file`)、フォルダー、シンボル、コードベース(`#codebase`)、ターミナル出力(`#terminalSelection`)、または`#fetch`と`#githubRepo`などのツールを明示的に参照します。

* **`@`メンション**: `@`を入力して`@vscode`や`@terminal`などの特殊なチャット参加者を呼び出します。それぞれは各ドメイン向けに最適化されています。

* **ビジョン**: スクリーンショットやUIモックアップなどの画像をプロンプトのコンテキストとして添付します。

* **ブラウザー要素** (実験的): [統合ブラウザー](/docs/debugtest/integrated-browser.md)から要素を選択して、HTML、CSS、スクリーンショットのコンテキストをプロンプトに追加します。

[AIのコンテキスト管理](/docs/copilot/chat/copilot-chat-context.md)について詳しく学びます。

## 変更を確認・管理

AIがファイルに変更を加えた後、それらを確認して受け入れるか破棄します。

* **インラインdiffを確認**: 変更されたファイルを開いて、適用された変更のインラインdiffを参照します。エディターのオーバーレイコントロールを使用して編集間を移動し、個別の変更を**保持**または**取り消し**します。詳細については、[AI生成コード編集の確認](/docs/copilot/chat/review-code-edits.md)を参照してください。

* **チェックポイントを使用**: VS Codeはチャット対話中の重要なポイントでファイルのスナップショットを自動作成でき、以前の状態にロールバックすることができます。詳細については、[チェックポイントと編集リクエスト](/docs/copilot/chat/chat-checkpoints.md)を参照してください。

* **ステージしてから受け入れ**: ソース管理ビューで変更をステージングすると、すべての保留中の編集を自動的に受け入れます。変更を破棄すると、保留中の編集も破棄されます。

![提案された変更を示すエディターのスクリーンショット。エディターのオーバーレイコントロールのレビューコントロールを強調表示しています。](../images/review-code-edits/copilot-edits-file-review-controls.png)

## より良い応答を得る

チャットはAI応答の品質と関連性を向上させるための複数の方法を提供します:

* **効果的なプロンプトを作成**: 望むものについて具体的に説明し、関連するファイルとシンボルを参照し、一般的なタスクに`/`コマンドを使用します。[プロンプト例](/docs/copilot/chat/prompt-examples.md)からインスピレーションを得るか、完全な[プロンプトエンジニアリングガイド](/docs/copilot/guides/prompt-engineering-guide.md)を確認してください。

* **AIをカスタマイズ**: [カスタム命令](/docs/copilot/customization/custom-instructions.md)を追加したり、再利用可能な[プロンプトファイル](/docs/copilot/customization/prompt-files.md)を作成したり、特殊なワークフロー用に[カスタムエージェント](/docs/copilot/customization/custom-agents.md)を構築したりしてAIの動作をプロジェクトに合わせてカスタマイズします。例えば、コード品質とチームのコーディング規約への準拠について、フィードバックを提供する「コードレビューアー」エージェントを作成します。

* **ツールを使用して拡張**: [MCPサーバー](/docs/copilot/customization/mcp-servers.md)を接続するか、ツールを提供する拡張機能をインストールしてエージェントに外部サービス、データベース、またはAPIへのアクセスを付与します。

詳細については、[VS CodeのAIをカスタマイズ](/docs/copilot/customization/overview.md)を参照してください。

## チャット対話のトラブルシューティング

[エージェントログとチャットデバッグビュー](/docs/copilot/chat/chat-debug-view.md)を使用してプロンプトを送信したときの動作を検査します。エージェントログはツール呼び出し、LLMリクエスト、プロンプトファイルディスカバリーの時系列イベントログを表示します。チャットデバッグビューは各対話のシステムプロンプト、ユーザープロンプト、コンテキスト、ツールペイロードを生で表示します。これらのツールはAIが特定の方法で応答した理由を理解したり、予期しない結果をトラブルシューティングしたりするのに役立ちます。
